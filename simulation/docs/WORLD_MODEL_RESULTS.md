# 面对面传接球与 WM：首批实验结果

2026-11-09，服务器 `<project-root>`。本次已完成开源技能接入、身体/球未来状态预测、当前学生采样数据上的教师蒸馏，以及服务器三轮交替训练和独立评估。**接球已改为面对面；WM 预测变准，但当前 WM 教师没有提高稳定接球表现。**

## 当前控制与参数

两台 K1 保留根部六自由度，初始相距约 1.2 m，双方初始朝向相反并指向彼此。运行中通过步态转向保持朝向；接球连续保持期间两台朝向误差均须 ≤30°。未固定骨盆、未用扶持力、未直接给球施加踢球外力。

底层为 B-Human 公开的独立 `K1_walk.onnx` 和 `K1_kick_inner_soft.onnx`，分别进行步态和踢球推理。50 Hz 推理、1 kHz MuJoCo 力矩积分；发送方 0.2–2.6 s 调用软踢球，其余时段调用步态；接收方调用步态。策略、许可、接口差异和架构详见 [WORLD_MODEL.md](WORLD_MODEL.md)。

主配置为 [`wm_pass_facing_gentle.yaml`](../configs/wm_pass_facing_gentle.yaml)，对照为 [`wm_pass_facing_gentle_no_wm.yaml`](../configs/wm_pass_facing_gentle_no_wm.yaml)。环境尺寸、球体质量/半径/惯量及接触参数仍由 [`hsl_m_3v3.yaml`](../configs/hsl_m_3v3.yaml) 管理；[参数说明](PARAMETERS.md)区分规则尺寸与未实测标定的工程初值。没有为提高成功率修改摩擦。

## 实际运行规模

| 项目 | 数值 |
|---|---:|
| WM 状态 | 1077 维，含两台身体/关节/控制历史、球位置与速度 |
| 学生输出 | 8 维技能指令，本课程只学习接收方平移 |
| WM | 2 个独立 MLP，各两层 256 隐藏单元 |
| 学生 | 两层 128 隐藏单元 MLP |
| 控制间隔 / 自回归拟合窗口 | 0.1 s / 8 步 |
| 回合时长 | 6 s，另有 0.8 s 初始化站立 |
| 三轮回放回合数 | 64 / 96 / 128 |
| 三轮累计实际转移数 | 3840 / 5760 / 7680 |
| 每轮 WM 更新 | 每个模型 700 次，batch 128 |
| 每轮教师 / 学生更新 | 查询 512 个学生状态 / 更新 400 次 |
| WM 固定验证 | 种子 10000–10015，整回合隔离 |
| 训练监测 | 种子 20000–20019 |
| 最终独立配对评估 | 种子 70000–70039，共 40 个相同初态 |

WM 在带探索噪声的当前学生数据上拟合。教师利用短期预测生成低速接球口修正，学生学习教师在自身访问状态上的动作。无 WM 对照保留相同网络、课程、采样数量和标注预算，教师直接使用当前状态，跳过 WM 拟合。两个训练程序的随机数消耗路径不同，不是逐梯度随机数完全相同的实验；训练种子各只有一组。

## 指标是否随训练改善

WM 预测误差来自固定验证集，单位 cm，预测时间为未来 1 s。未训练项是内置常速度/静止身体先验。

| 阶段 | 球位置 RMSE | 身体位置 RMSE | 独立评估严格成功率 | 跌倒率 |
|---|---:|---:|---:|---:|
| 未训练 / 原技能基线 | 17.75 | 14.58 | 7.5%（3/40） | 0% |
| WM 第 1 轮 | 9.12 | 4.50 | 10%（4/40） | 0% |
| WM 第 2 轮 | 9.06 | 4.41 | 15%（6/40） | 0% |
| WM 第 3 轮 | 8.19 | 4.13 | 5%（2/40） | 0% |
| 无 WM 蒸馏第 1 轮 | — | — | 30%（12/40） | 0% |
| 无 WM 蒸馏第 2 轮 | — | — | 25%（10/40） | 0% |
| 无 WM 蒸馏第 3 轮 | — | — | 27.5%（11/40） | 0% |

严格成功要求：发送方先碰球、接收方后碰球，球曾移动 ≥0.3 m，球在接收方根部 0.3 m 内、水平速度 <0.5 m/s、双方相向 ≤30°，连续保持 ≥0.3 s，且结束时仍满足保持条件、全回合无人跌倒。

各组独立评估都曾满足短暂接球窗口（100%），但稳定到结尾的比例很低。**不能把这个 100% 写成稳定传球成功率。** WM 第三轮相对无 WM 对照严格成功率低 22.5 个百分点，配对初态 bootstrap 95% 区间为 [-37.5, -7.5] 个百分点。区间只描述这组初态的变动，不能覆盖训练随机种子之间的变动。

预测误差下降，控制结果仍退化，说明“预测监督损失下降”不等于“教师的接球目标正确”。当前教师主要修正位置，仍可能让脚再次碰走已经减速的球；多步预测的偏差也会改变教师标注。需继续引入脚球接触、相对速度、最终持球奖励和接球脚缓冲技能，才能验证持续协同改进。当前不宣称已实现稳定 RSI 或循环回传。
